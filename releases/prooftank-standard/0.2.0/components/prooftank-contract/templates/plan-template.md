## ProofTank bounded work packet

```yaml
profile: standard
must_do: []
must_not_do: []
may_do: []
stop_when: []
required_checks: []
known_unknowns: []
providers:
  used: []
  unavailable: []
  degraded: []
```

Map every `REQ-*` and `INV-*` identifier to a task and deterministic check. Do
not treat agent output as deterministic evidence.
