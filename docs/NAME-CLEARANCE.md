# Preliminary name research

## Status

The project owner accepted `ProofTank` as the working name for an open-source
hobby project. The public repository is
[`calculatetech/prooftank`](https://github.com/calculatetech/prooftank).
`Proofmill` has a material software collision and must be replaced before the
next release. This is not legal advice or a trademark clearance opinion.

Search date: 2026-08-12.

## Material collision

An active public repository already uses the product name
[`ProofMill`](https://github.com/KanadeK/proofmill) for a Python command-line
tool. GitHub reports that the repository was created on 2026-07-30, is not
archived, and was pushed on 2026-08-09. Its current
[`pyproject.toml`](https://raw.githubusercontent.com/KanadeK/proofmill/main/pyproject.toml)
declares both the Python distribution name `proofmill` and the command
`proofmill`.

The other product checks print PDF files. This product distributes assurance
rules for agent-built software. The exact software product, distribution, and
command-name overlap is enough to require a human naming decision. This report
does not decide whether trademark law would find confusion.

## Replacement candidate: ProofTank

The exact searches for `ProofTank` and `Proof Tank` found no indexed software
product or exact trademark result. Search results contained only unrelated uses
of the separate words, such as descriptions of leak-proof or explosion-proof
tanks. Search indexing is incomplete and cannot establish legal availability.

Direct current checks found:

- no exact GitHub user, organization, or repository named `prooftank`;
- no repository returned by GitHub's `prooftank in:name` search;
- HTTP 404 for `prooftank` and `prooftank-standard` at npm, PyPI, crates.io,
  NuGet, and RubyGems; and
- no DNS resolution for `prooftank.com`, `prooftank.org`, `prooftank.dev`, or
  `prooftank.io`.

These are favorable collision signals, not reservations. A missing package,
account, or DNS record does not prove that another party has no rights or that a
registry will permit registration.

An HTTP 404 is not a reservation, ownership decision, or availability promise.
Registry state can change. No package ecosystem has been selected for this
project, and no name was reserved.

## Trademark search limits

The [USPTO search guidance](https://www.uspto.gov/trademarks/search/federal-trademark-searching)
says an exact-word search is only a first step. A search must also consider
similar marks and related goods or services. The
[WIPO Global Brand Database](https://www.wipo.int/en/web/global-brand-database)
does not replace searches of applicable national or regional offices.

This session could open the official search applications but could not produce
a reliable result set from their interactive JavaScript interfaces. More
importantly, the project has not selected jurisdictions, goods and services,
Nice classes, or risk tolerance. Those missing decisions make a legal clearance
conclusion impossible.
